# reji-birthday

Birthday treasure hunt and certificate for Reji's Claude Max subscription gift.

## Pages

- **Certificate** -- `docs/certificate.html` -- Printable landscape certificate (dark mode, Claude orange theme). Use browser "Print to PDF" in landscape mode with background graphics enabled.
- **Treasure Hunt** -- `docs/index.html` -- Interactive multi-stage experience with riddles, an unscramble game, memory cards, and the final gift reveal.

## Deployment

Served via GitHub Pages from the `/docs` directory on `main`.

Live at: [nirbhaypherwani.github.io/reji-birthday](https://nirbhaypherwani.github.io/reji-birthday)
